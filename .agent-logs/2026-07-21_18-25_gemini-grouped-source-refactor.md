## Goal
Refactor the massive single-file `gemini.js` userscript into 10 ordered source files under `userscripts/gemini-thread-saver/` while extending `bundler.js` to support script groups concatenated into a single shared IIFE scope.

## User Feedback & Decisions
- Branch: `refactor/gemini-grouped-source`
- Group configuration defined in `script_manifest.json` using `"group": "gemini-thread-saver"` and `"files": [...]`.
- Behavior and lexical scope preserved without ESM migration or changes to Tampermonkey loader metadata.

## Changes Made
1. **Bundler Extension (`bundler.js`)**:
   - Added support for loading `script_manifest.json` alongside auto-discovering remaining standalone `.js` scripts.
   - Added `files` array group handling: path safety checks, existence check, duplicate check, unreadability error, source boundary comments (`/* ===== file ===== */`), syntax validation via `vm.Script`, and source map generation.
2. **File Watcher (`watch-and-bundle.js`)**:
   - Added watching for `script_manifest.json` in addition to recursive `.js` file watching under `userscripts/`.
3. **Gemini Source Split (`userscripts/gemini-thread-saver/`)**:
   - `00-bootstrap.js`: Header metadata & outer IIFE start (`(function() { 'use strict';`)
   - `01-shared.js`: Font constants, tooltip singleton, and time/date formatters
   - `02-token-usage.js`: `estimateTokensAccurate`, thread message extraction, token calculation & badge UI
   - `03-timestamps.js`: Timestamp extraction, XHR/fetch patching, heuristic and embedded timestamp processing
   - `04-sidebar-dates.js`: Sidebar date extraction, rendering, layout, and GM menu settings
   - `05-prompt-tools.js`: Prompt timestamp prepending, phase prompt replacements (`/phase0`..`/phase3`), autocomplete & phase selector UI
   - `06-archive.js`: Local Markdown archive export, secret key management, and sync notices
   - `07-terminal.js`: Bash run-button injection, cross-origin local execution (`127.0.0.1:3033`), inline terminal output, session polling, context pills, and submission injection
   - `08-model-optimizer.js`: Gemini model dropdown optimizer and singleton observer setup
   - `09-page-observer.js`: Tab-title synchronization, adv upsell removal, page mutation observer orchestration, style injections, and outer IIFE closure (`})();`)
4. **Regression Test (`test-grouped-bundle.js`)**:
   - Built Node-based test confirming grouped concatenation, lexical sharing, order preservation, single dispatch invocation, and clear missing-file build failures.
5. **Documentation (`README.md`)**:
   - Documented grouped multi-file manifest entries with code examples.

## What Worked
- `node bundler.js` successfully builds `userscript_bundle.js` with 19 script entries (1 group + 18 standalone scripts).
- `node test-grouped-bundle.js` passes all lexical scope, load order, dispatch count, and failure mode assertions.
- Required Gemini symbols verified present in the bundle (`estimateTokensAccurate`, `calculateThreadTokens`, `processEmbeddedTimestamps`, `extractSidebarTimestamps`, `exportThreadWithTimestamps`, `terminalManager`, `startOptimizer`, `startObservers`).

## Architecture Notes
- All files in a group are wrapped inside a single outer function/IIFE wrapper generated by `bundler.js`, allowing all group files to share one lexical scope seamlessly without requiring an ESM module transformation.
